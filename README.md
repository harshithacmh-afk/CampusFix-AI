# CampusFix AI

## Multi-Agent Campus Facility Decision Support System

CampusFix AI is an Agentic AI system that helps facility managers diagnose equipment issues by retrieving similar historical maintenance cases and generating explainable recommendations.

## Core Features

- Semantic search over historical maintenance records
- Similar-case retrieval
- Multi-agent diagnosis
- Fix recommendations
- Cost and time estimation
- Urgency classification
- Explainable reasoning
- Technician feedback loop
- Continuous knowledge-base improvement
- Streamlit dashboard
